# Jack White — personal site

Personal site: work, music, and resume.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Pages: home, work index and case studies, music, about, HTML resume
- Site data in `lib/site.ts` and `lib/projects.ts`
- Your own copy goes in `lib/copy.ts`. Empty fields show a "Write this" prompt in `npm run dev` and render nothing in production.
- PDFs in `public/resume/`
- Hero photo in `public/images/jack-white.jpg`
